Flood Risk Prediction System

Case study

  1. Dataset
  2. Preprocessing
  3. Feature Engineering
  4. Train/Test Split
  5. Model Training
  6. Evaluation
  7. Flask Deployment

01Problem

Predict flood risk from environmental and climate-related factors to support disaster preparedness.

02Dataset

More than 50,000 environmental records across 20 risk factors.

03Features

Risk factors include rainfall intensity, deforestation, drainage systems and urbanization.

04Methodology

Data preprocessing, feature engineering and exploratory analysis with Pandas and NumPy, followed by hyperparameter optimization.

05Model Comparison

Multiple classification models were trained and evaluated with Scikit-learn. The system uses a Random Forest classifier.

06Evaluation

90.2% accuracy and 0.97 ROC-AUC. Matplotlib was used to visualize model performance and flood risk trends.

07Deployment

A Flask application serves real-time predictions, with an HTML, CSS and JavaScript front end and an interactive dashboard for risk patterns.

08Outcome

A working end-to-end system, from raw data to a deployed application.
